# Cycle07 execution contract

This contract supplements the previously committed
[observation design](2026-09-10-cycle07-observation-design.md) and the
[program grammar](2026-09-10-cycle07-program-grammar.md), written before candidate
enumeration. Its source identity, exact prepared fixture and execution code are

## Question and finite panel

Do two solver instructions yield observable correct answers, errors and
disagreements on mechanically verified tasks? This is feasibility for studying
actual joint error, not a fusion-performance experiment. G gives the ordinary
evaluation instruction; S specifically directs attention to state updates,
loop bounds and conditions. S is an audit prompt, not a proven specialist.

The fixed grammar admits short terminating integer programs and supplies the
candidate order, structural deduplication, numeric/step bounds and seed42 split.
Keep the first six accepted templates per stratum/truth cell, for24 total;
truth is computed, never selected from model behavior. Instrumented Python and
an independent AST evaluator check all24 Boolean answers and final integer
states before sealing. Candidate sources/exclusions and exact interpreter/code
identities remain in the preparation evidence. Normalization removes final
predicates, constants and consistent variable renaming; it establishes a
syntactic split criterion, not semantic or statistical independence.

Eight items are development and16 are reserved. Only the16 development
role/item payloads exist in the request order. Each item has adjacent G/S calls;
within each truth/stratum cell one item is G-first and one is S-first. Payload
bytes contain only program and role instruction, with a common frozen system
prompt asking for a JSON Boolean answer. No truth, ID, split, other answer,
research context or reserved program is sent. Sealing before calls means no
solver outcomes guide task or prompt selection in this batch.

## Primary, partial outcomes and stop

Primary is the complete eight-item joint2×2 error count table separately by
truth, plus stratum tables and exact descriptive quantities from the design.
All rates name their valid paired denominator. G error, S error, correction to
G, harm relative to G and S-minus-G error are measured on the same pairs.
Truth-conditioned joint-error excess is descriptive; task difficulty can create
association. No population uncertainty, dependence-cause or calibrated-model
claim is inferred from eight items and one response per role/item.

The full primary requires all eight valid pairs. Retain valid unpaired answers;
partial pair summaries are separately labeled and the full primary stays null.
Invalid format, provider refusal, truncation and unsent inputs are distinct
collection outcomes, never scored as mathematical errors. False is a valid
Boolean answer, not missing data.

The observability gate requires complete coverage, at least one correct and
one incorrect answer for each role, and at least one disagreement. It tests
minimum variation only. Zero observed errors or identical outputs are valid
outcomes that park this configuration. No automatic task expansion, reserve
consumption, answer-exposure arm or repair batch follows, even if the gate passes.
Stop after this one development batch, offline scoring, independent audit and
the interpretation checkpoint. A later experiment needs its own freeze.
