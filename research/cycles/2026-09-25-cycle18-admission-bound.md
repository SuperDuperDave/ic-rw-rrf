# Cycle18 — a pre-data restriction on new candidate admission

Recorded before the two variant bodies were acquired or evaluated. The
coordinator derived this bound during implementation; two independent Codex
workers checked the exact algebra and assumptions. It sharpens interpretation
without changing the frozen-intent policies, primary comparison or stop.

Let U0=A100∪S100 and F=(a+d+t)/3+s, using nonnegative reciprocal contributions
with one-based k60 ranks. If x lies outside U0, both a(x) and s(x) vanish. Even
if both new variants rank x first,

`F(x) <= 2/(3*61) = 2/183`.

Each of the ten distinct S-head documents y receives at least its own S
contribution, so `F(y) >= 1/70`. The exact separation is

`1/70 - 2/183 = 43/12810 > 0`.

Therefore **F10 is a subset of U0 on every query for every input permitted by
this protocol**. This is a strict score certificate; tie handling, labels,
source independence and actual run contents are irrelevant to the proof.
It depends on the declared coefficients, cutoff, rank origin and at least ten
S documents. It does not apply to arbitrary family sizes or weights.

The additional sources expand the input candidate union but cannot expand the
displayed top-ten pool beyond original A/S access here. They can change support
and scores of old candidates, including through their original ranks after
other documents enter their lists. Do not remove new documents and renumber
source ranks when interpreting this conclusion.

Any actual F-head coverage failure would be a contract or implementation error.
Keep the general diagnostic's coverage branch and synthetic test, but expect
zero such failures in this experiment. Any observed scalar infeasibility must
come from a head set inside the old pool, a more specific capability statement.
The fixed-score restriction of F to U0 has the same top-ten set by proof; no
additional scored counterfactual arm is needed to establish that fact.

This is an application of the same elementary score-bound idea used in cycle16,
not a novel fusion method. It offers no relevance guarantee: different orderings
inside U0 can help, harm or be equivalent. The primary F−H missing-label bounds
and fixed standalone references still determine the empirical conclusion.
